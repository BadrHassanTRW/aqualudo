# 07. Admin Booking Management

## Goal
A simple admin view of today's bookings for AquaLudo, with the ability to confirm or cancel each one. This is the minimum staff need to run the day-to-day operations on the ground.

## User Stories (MVP)
- As an admin, I want to see a table of today's bookings (customer name, activity, time, party size, payment status), so that I know who is showing up.
- As an admin, I want to see a customer's phone number in the table, so that I can call them if needed.
- As an admin, I want to mark a booking as confirmed, so that the day's list reflects the real attendance plan.
- As an admin, I want to cancel a booking from the list, so that I can free a slot when a customer calls to cancel.
- As an admin, I want to manually add a new booking on behalf of a walk-in or phone-in customer, so that we never lose a conversion.

## Out of Scope (for MVP)
- Filters, search, and pagination beyond today
- Rescheduling, refunds, and partial refunds
- No-show automation and attendance tracking
- Waitlist reassignment and offer windows
- Multi-resource conflict detection
- Recurring bookings and custom rules
- Bulk actions, CSV export, PDF export
- Calendar week/day view
- Payment status override and payment transaction log
- Customer WhatsApp message thread view
- Overbooking protection and admin override
