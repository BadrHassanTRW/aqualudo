# Task 02. Activities & Pricing Catalog

## Goal
Build the public catalog surfaces that let visitors browse AquaLudo's five activities (Rowing, Kayaking, SUP, Wakeboarding, Fitness), inspect per-activity details with pricing tiers, and view session packages and memberships on a dedicated `/pricing` page. Pricing is hard-coded in a content file plus a small `reviews` table in Postgres; no admin UI, filters, or comparison tables in the MVP.

## Steps
1. **Define data shapes and seed content** — Author `content/activities.ts` exporting a typed `Activity` array (id, slug, name, short description, hero image path, pricing tiers array, what's-included, what-to-bring) for all five activities, plus `content/packages.ts` and `content/memberships.ts` for session bundles and monthly tiers. Files: `content/activities.ts`, `content/packages.ts`, `content/memberships.ts`, `types/catalog.ts`. Notes: prices in EGP as integers, slug = URL path segment.
2. **Create reviews schema and seed** — Add a `reviews` table to Supabase with columns `id uuid pk`, `activity_slug text`, `rating int check (1..5)`, `author_first_name text`, `body text`, `approved bool default false`, `created_at timestamptz default now()`, plus an index on `(activity_slug, approved)`. Insert ~3 approved rows per activity via a SQL seed file `supabase/seed_reviews.sql`. Files: `supabase/schema/reviews.sql`, `supabase/seed_reviews.sql`.
3. **Build the activities listing page** — Server component at `app/activities/page.tsx` that imports `content/activities.ts`, renders a responsive grid of `ActivityCard` components (image, name, short description, "from X EGP/hr" price, "Book now" button linking to `/book?activity=<slug>`). Files: `app/activities/page.tsx`, `components/catalog/ActivityCard.tsx`, `components/catalog/ActivityGrid.tsx`.
4. **Build the activity detail page** — Dynamic route `app/activities/[slug]/page.tsx` (generateStaticParams from the content file for SSG) that renders hero image, long description, included/bring lists, pricing tier table, and a "Reviews" section fetching approved rows from Supabase. Add a sticky "Book now" CTA. Files: `app/activities/[slug]/page.tsx`, `components/catalog/PricingTierTable.tsx`, `components/catalog/ReviewsList.tsx`, `lib/reviews.ts`.
5. **Build the `/pricing` page** — Server component at `app/pricing/page.tsx` with two sections: "Session Packages" (cards from `content/packages.ts`) and "Monthly Memberships" (cards from `content/memberships.ts`), each card showing price, session count or duration, and a bullet list of benefits. Files: `app/pricing/page.tsx`, `components/catalog/PackageCard.tsx`, `components/catalog/MembershipCard.tsx`.
6. **Wire navigation and home cross-links** — Add an "Activities" and "Pricing" link to the global header in `components/site/Header.tsx`, and a "View all activities" CTA on the home page's activities teaser pointing to `/activities`. Files: `components/site/Header.tsx`, `app/page.tsx` (edit existing home page teaser block only).
7. **Add empty and missing-data handling** — If a slug in `[slug]` is not in the content file, call `notFound()` to render `app/not-found.tsx`; if a detail page has zero approved reviews, render a "Be the first to review" placeholder instead of an empty list. Files: `app/activities/[slug]/page.tsx`, `app/not-found.tsx`. Notes: keep 404 styled with the same header/footer.
8. **Smoke test and mobile pass** — Run `npm run dev`, verify the five detail pages render the right pricing tiers, the "Book now" buttons carry the activity slug through to `/book?activity=...`, reviews appear on each detail page, `/pricing` shows both sections, and layouts reflow correctly at 375px width. Files: local browser only.

## Acceptance Criteria
- [ ] Visiting `/activities` shows a grid of exactly five cards (Rowing, Kayaking, SUP, Wakeboarding, Fitness), each with image, name, short description, a "from" price in EGP, and a visible "Book now" button.
- [ ] Clicking an activity card navigates to `/activities/<slug>` and the page displays the hero image, long description, what's included, what to bring, all configured pricing tiers (e.g. Rowing shows both 200 EGP/hr and 400 EGP/hr), and a "Book now" button.
- [ ] The "Book now" button on both the card and the detail page navigates to `/book?activity=<slug>` with the correct `activity` query parameter visible in the URL.
- [ ] Each activity detail page shows a "Reviews" section with at least one approved review from Supabase (star rating, first name, short text); pages with no approved reviews show a "Be the first to review" placeholder instead of an empty list.
- [ ] Visiting `/pricing` shows a "Session Packages" section and a "Monthly Memberships" section, each with at least one card listing price, scope (sessions or month), and a bullet list of benefits.
- [ ] The global header contains visible links to "Activities" and "Pricing" on every page, and the home page has a working "View all activities" link pointing to `/activities`.
- [ ] Visiting `/activities/unknown-slug` renders the 404 page, not a blank or broken layout.
- [ ] All catalog pages are usable at 375px width: no horizontal scroll, images scale, buttons remain tappable, and the pricing tier table is readable (stacks vertically or scrolls within its container if needed).
